Datasets for Siraj
Assalamu Alaikum!

This release hosts the official Tafsir and Translation datasets for the Siraj Quran app.

To keep the initial app download light and fast, these files are downloaded on-demand whenever a user chooses to read or study with a specific Tafsir.
What's included in this release:

-Arabic Tafsirs:
Ibn Kathir, Al-Qurtubi, Al-Muyassar, Aysar Al-Tafasir (Al-Jazairi), Ibn Al-Qayyim, and Al-I'rab.

-English:
Tafsir Ibn Kathir, Mukhtasar (Abridged Explanation), Al-Jalalayn, and Muhammad Asad translation.

Turkish:
As-Sa'di, Ibn Kathir, Turkish Mukhtasar, and Muslim Shahin translation.

Urdu:
Tafsir Ibn Kathir, Tafsir As-Sa'di, and Maulana Wahiduddin Khan translation.

All files are formatted as clean JSON mapped directly by Ayah number for seamless offline reading once downloaded.
